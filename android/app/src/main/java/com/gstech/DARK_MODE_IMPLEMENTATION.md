# GSTech dark mode update

Dark mode is disabled by default and persisted through ThemeController.
The palette follows `dark mode example.pdf`: deep navy background, blue-tinted surfaces/cards, bright blue primary accents, teal secondary accents, and light text.

Formateur and student profile switches now update the same global theme controller as the admin area. Shared color accessors follow MaterialTheme so cards, text, dividers and surfaces adapt across screens.
